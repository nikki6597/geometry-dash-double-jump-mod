# platformer double jump #

mod by claude & andrey

# How to use it? #

The mod can only work in platformer mode, this can be changed in the mod settings.

• tap - jump (cube)
• hold - big jump (robot)

# explanation #

The mod determines which mode and what type of mode 

for example - cube, robot, ship(jetpack), ball, spider, swing copter, ufo, wave. 

platformer/normal mode works

# settings #

There are settings, for example, to disable "platformer mode"
you can choose which jump mode (optional), as well as the time when you can press, etc.
